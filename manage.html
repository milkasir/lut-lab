令牌选择 Only select repositories，只选这个仓库，Repository permissions 的 Contents 设为 Read and write。仓库地址会记住；令牌只留在当前页面内存，刷新后需要重新输入。令牌仅发送给 GitHub API。

第一次使用与发布说明
  1. 先将完整站点部署到 GitHub Pages，再打开网址末尾的 manage.html。
  2. 连接对应仓库，上传文件。名称可以直接沿用文件名；不清楚 LUT 输入时保留「未知」。
  3. 点「发布更新」会把选中素材公开保存到连接的仓库。Pages 的发布分支需与这里的分支一致，等待部署完成即可。

连接时读取最新清单，发布时合并其他人的新增内容。相同条目冲突时会停止并保留待发布文件，避免覆盖他人的修改。点「删除」先标记，发布前可撤销；发布后条目及对应图片、缩略图或 CUBE 会从当前分支删除。Git 的历史提交仍可能保留旧文件，误传敏感内容时还需清理历史。

这是 GitHub Pages 的纯静态在线管理方案。无需额外服务器，但每次重新打开管理页都要授权。关闭页面或断开连接即清除当前令牌。

离线更新包（备用方式）

不连接 GitHub 也可以整理图片和 LUT，下载完整清单及新文件，手动合并到站点目录后提交。

管理入口独立于公开比较工作台。只有持有仓库写入授权的人可以发布更新。
