# LUT 编辑器

在工作台点击「新建 LUT」，或在任意窗格点击「复制到编辑器」。也可以从 LUT 详情进入编辑器。默认新建为标准输入的恒等 LUT。

## 可调整的颜色工具

- 基础明暗：曝光、亮度、对比与对比中心、高光、阴影、黑白色阶、中间调 Gamma、褪黑。
- 白平衡：相对色温与绿/洋红偏移。它们是线性 RGB 增益调整，不代表经过相机标定的绝对开尔文值。
- 色彩：全局色相、饱和度、自然饱和度、黑白比例与 RGB 黑白权重。
- 总曲线及独立 RGB 曲线：2–16 个控制点，形状保持的三次 Hermite 插值；支持鼠标、触摸、方向键及数值输入。
- 八色 HSL：红、橙、黄、绿、青、蓝、紫、洋红分别调节色相、饱和、明度。
- 分区调色：阴影、中间调、高光各自的色相、浓度、亮度及分区平衡。
- RGB 一级调色：各通道的 Lift、Gamma、Gain、Offset；独立输入/输出黑白点；3×3 通道混合矩阵。
- 调色总强度、RGB 直方图、原图分割和按住查看原图。

普通 3D LUT 只能保存逐像素颜色映射。本编辑器不会把颗粒、锐化、降噪、暗角或局部蒙版伪装成 LUT 功能，也不写入松下的私有画质调整标签。

## 窗格复制与输入

复制窗格会包含当前前置编码、曝光、前置 LUT、主 LUT、强度及插值方式。新 LUT 的输入取自该窗格图片的实际编码标记，而不只是原 LUT 的文件名。原图窗格按当前未处理原图复制。

颜色处理顺序为：输入转换 → 原窗格完整颜色流程 → 线性曝光/白平衡 → 色阶/对比/明暗/RGB 一级调色 → 总曲线及 RGB 曲线 → 通道混合 → HSL 与全局饱和 → 分区调色 → 黑白混合 → 调色强度 → 显示范围裁切。

标准 sRGB、V-Log/V-Gamut、F-Log2/F-Gamut 之间有实际数值转换。新建 V-Log 或 F-Log2 工程会包含到 sRGB 的显示变换；它不是 Log 数值恒等表。Cinelike D2 与单色格调没有通用逆变换，应配合相应原片使用。未知基底必须先由使用者确认，才允许导出到松下。

预览先使用 17³ 网格响应操作，停止调节后细化为 33³；保存和导出均为完整 33³。输入照片已经丢失的信息不能恢复。相机内照片格调、白平衡、曝光、显示处理和插值实现仍可能造成实拍差异。

## 保存与备份

「保存并加入对比」将完整工程和生成的 CUBE 存入本机 IndexedDB，并作为「我的创作」加入工作台。修改同一已保存工程会更新该项及使用它的窗格；复制已编辑 LUT 则生成独立副本。最多保留 24 个本地工程。

草稿自动在本机暂存，可在编辑器中恢复。临时上传的参考图仍属于本次会话；工程不会嵌入照片。工程可以下载为 `.lutlab.json`，包含源 LUT、完整颜色流程、曲线及参数，可跨设备重新导入编辑。

若浏览器禁用本地存储或配额不足，生成的 LUT 仍可进入本次会话对比，并明确提示下载工程备份。工程不会自动发布到公共素材库；需要共享时可下载 CUBE，再从管理页上传。

## 松下导出

使用「导出松下 CUBE」：

1. 生成 33×33×33、红通道变化最快的标准 3D CUBE，完整范围 0–1；不混合 1D 表。
2. 写入正确的 `#LUMIXPHOTOSTYLE` 标记：STD、VLOG、CNED2 或 MONO。
3. F-Log2 工程会先实际烘焙 V-Log/V-Gamut → F-Log2/F-Gamut 的输入桥接，再声明为 VLOG；不会只改标记。
4. 文件名采用 1–8 位英文字母/数字，兼容 FAT32 卡的短文件名要求。
5. 将文件放到卡根目录，在机身「LUT 库」载入；或先导入 LUMIX Lab 的设备库，再传到机身。必须使用支持对应功能的机型和固件，并匹配照片格调。

格式依据：[DC-S9 官方 LUT 库说明](https://eww.pavc.panasonic.co.jp/dscoi/DC-S9/html/DC-S9_DVQP3138_eng/0074.html)及 [LUMIX Lab LUT 导入说明](https://av.jpn.support.panasonic.com/support/global/cs/soft/lumix_lab/en/cts/d0.html)。已用独立 CUBE 解析器、数学测试和浏览器下载流程验证格式；尚未做真实机身导入测试。

## 开发验证

- `node --test tests/*.test.cjs`：颜色数学、恒等与通道顺序、窗格处理链、Log 转换、CUBE 往返、曲线、数值边界和非法工程输入。
- 浏览器检查（需 Playwright 与 Chromium；可用 `CHROMIUM_PATH` 指定 Chromium 路径）：`node tests/editor.browser.cjs` 与 `node tests/editor-edge.browser.cjs`。覆盖：新建/复制、曲线、撤销重做、工程导入导出、保存后对比、刷新恢复、更新不重复添加、F-Log2 到 V-Log 导出、浅色/深色和 320–1920 像素布局。
- 所有处理、项目与草稿均留在浏览器；公共清单仍只在打开页面或手动刷新时读取。

## 试用包

解压预览包后，安装 Python 3。Windows 可双击 `START-PREVIEW.cmd`；其他系统运行 `python3 preview.py`。浏览器会打开 `http://127.0.0.1:8765/`。保持终端窗口打开，退出时按 Ctrl+C。

本地工程按浏览器和网站来源隔离。本机预览的工程不会自动出现在正式站，建议下载工程文件在需要的站点重新导入。
