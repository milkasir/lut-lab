# LUT LAB · 在线调色实验室

在浏览器中比较 LUT 风格，选择喜欢的色彩并导出效果预览。

**[打开在线实验室](https://lut.nbuna.cc/)**

- 自带示例图片和 LUT，也支持上传自己的照片与 `.cube` 文件。
- 自由新增对比窗格，每格可独立选图、选 LUT、调强度。
- 支持原图分割比较、收藏和参数方案。
- 一键导出 PNG / JPEG 效果对比图。

网页顶部的「管理素材库」可维护公共图片和 LUT，发布更新需要对应 GitHub 仓库的写入授权。

本地预览：

```sh
node tools/serve.cjs
```

纯静态站点，可部署到 GitHub Pages，无需安装依赖或构建。
