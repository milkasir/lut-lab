文件能读取，并不代表输入图片的编码适合它。标准 JPG 可直接比较 STD 风格；D2 与 Log LUT 需要相应基底的素材。各窗格的「输入与转换」可以选择前置 LUT，或从标准图片编码到 V-Log / F-Log2。

FLog2_NC 和 FLog2_PROVIA 已由库维护者验证使用 F-Log2 转换。选择这两款时，「自动匹配」会给标准图片应用 F-Log2 前置编码；图片已标为 F-Log2 时直接输入。原文件的 VLOG 注释保留，站点按已验证的 F-Log2 元数据处理。

MONO 标记表示单色照片格调输入；请使用匹配的单色素材，改变编码标签不会把彩色图片转成黑白。列表中的单色效果也可能接受 STD 彩色输入，以各文件输入标记为准。

前置编码以 sRGB 反解线性、转换色域后重新编码 Log，不会恢复照片已经丢失的高光和场景信息。D2 请使用 D2 原片或经过验证的前置转换 LUT。浏览器处理显示用 sRGB 图片；Log 图请准备保留原始数值、没有自动显示变换的 PNG/JPG。

所选 LUT 使用 100% 强度、自动匹配输入（已确认的 F-Log2 会自动转换标准图片）；如需自定义参数，请从当前窗格导出。

从一张照片开始。

  1. 选图片。点击素材缩略图，再点「应用到所有窗格」。也可以在单个窗格中选择不同图片。
  2. 挑 LUT。点击窗格中的 LUT 菜单，可搜索名称；或在素材库勾选多款后点「对比所选 LUT」。点「新增窗格」继续添加，点窗格右上角 × 移除。
  3. 做自己的 LUT。点「新建 LUT」从初始基底开始，或点窗格中的「复制到编辑器」继续微调；保存后会加入本机 LUT 列表与工作台对比。工程可下载备份，也能导出松下机身使用的 CUBE。
  4. 看变化。调整强度、切换分割视图；打开「输入与转换」设置前置编码或转换 LUT。自动匹配会为普通图片转换已验证的 F-Log2 LUT 输入，F-Log2 原片直接输入。
  5. 导出。素材库有勾选时，「一键导出」下载所选 LUT 在当前图片上的总览（100% 强度、自动匹配输入）；没有勾选时导出当前窗格参数。「导出对比图」可自定义内容、图片、尺寸和格式。
  6. 留方案。保存 / 载入 JSON 参数方案。临时上传的图片和 LUT 刷新后需重新上传；编辑器保存的工程会保留在本机，建议同时下载工程备份；方案按文件名重新匹配它们。

支持浏览器可解码的 JPG、PNG、WebP、AVIF 和标准 .cube；RAW / HEIC 请先转成 PNG / JPG。最大 LUT 70 MB，图片 40 MB；显示预览保留完整构图。导出按选择的每格宽度处理，最大整张 32 MP。
